# 上线首个可浏览的日报网站

## What to build

创建 Tech Daily & Weekly 的首条端到端阅读路径：Astro 从 Markdown 加载一份符合领域模型的示例日报，并通过编辑型、文字优先的响应式界面提供最新日报、历史归档、栏目/核心主题筛选和全文搜索。站点面向公开访问，但禁止搜索引擎索引且不加载访问分析脚本。

建立私有 GitHub 仓库连接 Zeabur 的最小部署链路，使示例日报可以从内容提交更新到公开网站。

## Acceptance criteria

- [ ] Astro 项目可在本地安装、构建和预览，使用严格的 TypeScript 配置。
- [ ] Markdown 内容模型能够表达报告日期、内容形态、核心主题、标题、正文和关键来源。
- [ ] 首页展示最新日报，归档页可按日期访问历史日报。
- [ ] 读者可以按内容栏目和核心主题筛选，并搜索标题、摘要与分析正文。
- [ ] 页面在桌面与移动视口均可阅读，采用编辑型、文字优先设计。
- [ ] 所有页面设置 `noindex`，且不包含分析、追踪或来源图片请求。
- [ ] 私有 GitHub 仓库更新后，Zeabur 能成功构建并发布示例日报。
- [ ] 自动化测试覆盖 Markdown Schema 校验和至少一条关键阅读路径。

## Blocked by

None - can start immediately
