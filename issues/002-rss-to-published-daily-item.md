# 从 RSS 自动生成一条可发布日报内容

## What to build

打通第一条自动内容链路：从可配置的中英文 RSS/Atom 来源读取候选信息，将原始正文保存在 Git 忽略的本机缓存中，经可替换的云端模型接口完成初筛和中文生成，通过 Schema 与来源检查后写入日报 Markdown，并由现有 Astro 网站展示。

模型接口需要分别支持低成本初筛模型和高质量生成模型，但具体服务商与模型名称只能由本机环境变量配置。

## Acceptance criteria

- [ ] 来源配置可以声明 RSS/Atom 地址、名称、语言、默认核心主题和启停状态。
- [ ] 采集器只处理目标北京时间自然日内发布的条目，并保存原始发布时间和发现时间。
- [ ] 原始抓取内容与模型中间结果只写入 Git 忽略的本机缓存。
- [ ] 模型服务商、初筛模型和生成模型均可通过环境变量替换，密钥不会写入仓库或日志。
- [ ] 英文来源生成简体中文内容，同时保留必要的原文术语与原始链接。
- [ ] 生成结果通过内容 Schema、日期和来源校验后写入日报 Markdown。
- [ ] 一条真实或固定测试 RSS 条目可以从采集命令端到端出现在网站日报中。
- [ ] 测试使用固定响应替身，不依赖真实模型费用或外部网络稳定性。
