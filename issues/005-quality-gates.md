# 执行候选池、核验与部分发布质量门

## What to build

在公开发布前执行达标制筛选和失败关闭的质量门。未达到日报门槛的信息进入本机候选池；达到最低来源质量但不值得展开的信息可进入雷达快讯；高影响且未获官方确认的消息只有在两个相互独立的可信来源支持时才能进入正式栏目。单个条目或栏目失败时，只发布其余通过检查的内容。

## Acceptance criteria

- [ ] 相关性、影响力、新颖性和可信度用于内部筛选，但数字评分不出现在公开页面。
- [ ] 未达到日报门槛的内容写入本机候选池，不出现在网站。
- [ ] 候选内容获得新证据或形成趋势后可以重新评估。
- [ ] 高影响未官宣消息需要两个相互独立的可信来源才能进入正式栏目。
- [ ] 未满足正式核验门槛但达到最低来源质量的消息，只能进入雷达快讯并标注“未确认”。
- [ ] 受限正文不会被绕过；仅基于公开摘要生成时，内容会明确标注未读取全文。
- [ ] 来源、内容 Schema、日期或事实一致性检查失败的条目不会发布。
- [ ] 部分条目失败不会阻断其他有效条目或栏目的 Markdown 生成。
- [ ] 测试覆盖候选晋级、双来源核验、受限正文和部分发布场景。
