# 接入 GitHub、论文与技术社区来源

## What to build

在统一来源协议下接入 GitHub、论文/研究机构和技术社区三类入口，使它们产出的候选信息经过与 RSS 相同的缓存、分类、信息簇、质量门和 Markdown 发布链路。第一版优先使用公开 RSS 或无需认证的 API；只有遇到明确限额瓶颈时才允许增加平台 Token。

提供覆盖核心主题的可编辑默认来源清单，来源发现不会自动永久加入配置。

## Acceptance criteria

- [ ] GitHub 入口可以读取重点仓库 Releases 及公开的趋势或动态信息。
- [ ] 论文入口可以读取 arXiv 或研究机构公开源，并保留论文、代码和机构链接。
- [ ] 社区入口可以读取至少一个无需认证的 Hacker News、Reddit 或同类公开源。
- [ ] 三类适配器都输出与 RSS 相同的标准化候选结构。
- [ ] 默认来源清单覆盖五个核心主题，并可通过配置启停或增删。
- [ ] 匿名访问达到限额时会产生可诊断日志，不会把凭证写死在代码中。
- [ ] 某个适配器失败不会阻断其他来源继续生成有效内容。
- [ ] 集成测试使用固定响应验证三个入口到最终日报的完整路径。
