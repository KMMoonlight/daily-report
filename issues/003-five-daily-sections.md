# 生成五类日报栏目与专业化展示

## What to build

将自动日报扩展为五种稳定内容形态，并让每种形态从分类、生成、校验到页面展示采用匹配其价值的表达方式：产品与工具突出用途和直达链接，研究与开源成果突出能力与证据，深度内容提供描述、总结和分析，行业动态概括事实与影响，雷达快讯保持一句话密度。

AI/智能体、开发者工具、芯片/算力、机器人/自动驾驶和消费电子/互联网产品作为可多选核心主题标签，而不是一级栏目。

## Acceptance criteria

- [ ] 内容 Schema 明确定义五种内容形态及各自必填字段。
- [ ] 成果型条目包含用途或能力说明，并提供产品、代码或论文直达链接。
- [ ] 深度内容包含描述、总结、证据优先的分析以及原文链接。
- [ ] 行业动态明确区分事实、来源观点和系统综合判断。
- [ ] 雷达快讯保持简短，并可明确标注“未确认”。
- [ ] 同一条目可以拥有多个核心主题标签，筛选结果不产生重复条目。
- [ ] 日报和网站使用与内容形态匹配的展示模板。
- [ ] 测试覆盖五种形态的有效样例、缺失必填字段和渲染结果。
