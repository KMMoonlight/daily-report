# 自动执行每日采集、回填与 Git 发布

## What to build

将日报流水线作为 macOS 本机定时任务运行：每天北京时间 09:00 生成前一自然日的日报，包括周末和节假日。电脑关机或休眠导致漏跑时，下一次运行按原始发布时间逐日回填。通过质量门的 Markdown 自动提交并推送 Zeabur 监控的部署分支；发生 Git 冲突时停止，绝不强推。

运行失败只写日志并静默重试最多三次。来源流量显著偏离历史基线时隔离该来源，其他来源继续处理。

## Acceptance criteria

- [ ] 安装命令可以为当前用户配置并验证 macOS 定时任务。
- [ ] 调度使用 `Asia/Shanghai`，每天 09:00 处理前一自然日。
- [ ] 运行账本记录每个日报日期的开始、成功、部分成功或失败状态。
- [ ] 检测到缺失日期时按日期顺序逐日回填，而不是合并为一份当前日报。
- [ ] 已发布日报不会因迟到信息被修改；迟到信息可留给周报评估。
- [ ] 每次失败静默重试最多三次，并记录不含密钥和正文的结构化日志。
- [ ] 来源数量异常时只隔离异常来源，正常来源继续处理。
- [ ] 通过检查的 Markdown 自动提交并推送部署分支。
- [ ] 推送前同步远端；出现冲突、非快进或工作区异常时安全停止且不强推。
- [ ] 可用受控时钟和临时仓库测试正常运行、漏跑回填、重试与冲突场景。
