# 合并信息簇并追踪持续主题

## What to build

让多个来源围绕同一底层成果或事件形成一个信息簇，并以最合适的内容形态在日报中占据一个位置。为跨日演进的事件建立持续主题，后续日报只呈现新增事实，同时能够链接此前脉络。全部被采纳来源需要持久化，页面默认展示关键来源并折叠其余来源。

## Acceptance criteria

- [ ] 标准化后的来源条目具有稳定身份、规范 URL、发布时间和内容指纹。
- [ ] 标题不同但指向同一成果或事件的来源可以合并为一个信息簇。
- [ ] 信息簇选择一个主内容形态和关键来源，其他来源作为事实或分析补充。
- [ ] 页面默认展示关键来源，并允许展开全部采纳来源。
- [ ] 跨日报的新进展能够关联到同一持续主题，只描述相对上一状态的新增事实。
- [ ] 历史脉络链接可以从当前条目访问此前相关日报。
- [ ] 去重与持续主题元数据长期保留，不随原始正文缓存清理而删除。
- [ ] 测试覆盖重复来源、URL 变体、相似但不同事件和跨日更新场景。
