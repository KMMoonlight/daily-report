# 完成生产运行验收与故障恢复

## What to build

将完整系统验收到可长期无人值守运行的状态。提供安装、来源配置、模型切换、本地缓存、定时任务、Git 发布、Zeabur 部署和故障恢复说明，并通过受控演练验证正常日报、周报、离线回填、部分失败、来源隔离、更正和缓存清理。

第一份正式日报从首次成功运行的前一自然日开始，不回填上线前历史。

## Acceptance criteria

- [ ] 文档说明本机依赖、环境变量、来源配置、GitHub 和 Zeabur 设置步骤。
- [ ] 文档提供安装、手动运行、定时运行、暂停、恢复和卸载命令。
- [ ] 配置检查能在任务启动前发现缺失密钥、无效来源和不可写缓存目录。
- [ ] 演练验证每天 09:00 日报与每周一 10:00 周报的时区和统计窗口。
- [ ] 演练验证电脑离线后的逐日回填和上线前历史不回填。
- [ ] 演练验证三次重试、来源异常隔离、部分发布和 Git 冲突安全停止。
- [ ] 演练验证周报后缓存清理以及元数据、已发布内容继续可用。
- [ ] 演练验证不可变历史和更正条目的双向展示。
- [ ] 生产构建不包含密钥、本机原始缓存、访问分析脚本或可索引指令。
- [ ] 首份正式日报成功推送后，Zeabur 自动部署且公开页面可访问。
