# 生成并发布每周综合报告

## What to build

每周一北京时间 10:00，基于上一个周一至周日的信息簇生成周报。周报先给出证据优先的全局趋势综合，再按产品与工具、研究与开源成果、深度内容、行业动态和雷达快讯列出一周精选。它不是日报拼接，也不设置“创作素材”栏目。

周报可以考虑因发现过晚而未进入日报、但原始发布时间属于该周的信息。周报成功生成后，删除对应周期的本机原始正文和模型中间结果，同时长期保留来源元数据、去重指纹和已发布内容。

## Acceptance criteria

- [ ] 周报周期严格按 `Asia/Shanghai` 的周一 00:00 至周日 23:59:59 计算。
- [ ] 全局趋势综合会跨日报合并重复事实，并明确区分事实、来源观点和系统判断。
- [ ] 精选内容按五种内容形态组织，并链接对应来源或日报条目。
- [ ] 周报不会包含单独的“创作素材”栏目。
- [ ] 迟到信息可以按原始发布时间参与周报，但不会反向修改历史日报。
- [ ] 部分栏目生成失败时，只发布通过质量门的综合与精选内容。
- [ ] 周报成功发布后清理该周本机原始正文和模型中间结果。
- [ ] 清理不会删除来源元数据、去重指纹、持续主题或已发布 Markdown。
- [ ] 测试覆盖跨日去重、迟到信息、部分发布和缓存清理。
