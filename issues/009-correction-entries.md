# 发布不可变历史的更正条目

## What to build

保持已发布日报和周报内容不可修改。发现事实错误、来源撤回或摘要有误时，在后续日报中发布更正条目，并通过稳定标识与原条目双向关联。旧报告页面必须动态显示后续更正，避免从历史链接进入的读者只看到已知错误。

## Acceptance criteria

- [ ] 已发布报告具有稳定且不会因标题变化而改变的报告与条目标识。
- [ ] 更正条目包含原条目引用、更正事实、原因、发现时间和支持来源。
- [ ] 更正只通过新增内容实现，不重写或删除历史 Markdown。
- [ ] 后续日报正常展示更正条目并链接原条目。
- [ ] 原条目页面能够从独立更正索引反向显示所有后续更正。
- [ ] 搜索结果和信息簇详情会提示条目存在更正。
- [ ] 缺失原条目、循环更正或重复更正无法通过内容校验。
- [ ] 测试证明原报告文件保持字节不变，同时旧页面能显示新增更正。
